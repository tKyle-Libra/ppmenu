## 🚀 上传方法

### 方法 1：使用 GitHub 网页（推荐，最简单）

1. **打开仓库页面**
   ```
   https://github.com/tKyle-Libra/ppmenu_assets
   ```

2. **进入 db 目录**
   - 点击 `db` 文件夹

3. **上传文件**
   - 点击 "Upload files" 按钮
   - 拖拽或选择所有 `data-page*.json` 文件（15个）
   - 在提交信息中填写：
     ```
     Add paginated data files (15 pages, 283 products)
     ```
   - 点击 "Commit changes" 提交

### 方法 2：使用 Git 命令行

```bash
# 1. 克隆仓库（如果还没有）
cd ~/Code/AI
git clone https://github.com/tKyle-Libra/ppmenu_assets.git
cd ppmenu_assets

# 2. 复制分页文件到仓库
cp -r /Users/tong/Code/AI/product-list-vite/data-pages/db/* db/

# 3. 提交更改
git add db/data-page*.json
git commit -m "Add paginated data files (15 pages, 283 products)"
git push origin main
```

### 方法 3：使用 GitHub CLI

```bash
# 1. 进入分页文件目录
cd /Users/tong/Code/AI/product-list-vite/data-pages

# 2. 使用 gh 命令上传
gh repo clone tKyle-Libra/ppmenu_assets /tmp/ppmenu_assets
cp -r db/* /tmp/ppmenu_assets/db/
cd /tmp/ppmenu_assets
git add db/data-page*.json
git commit -m "Add paginated data files"
git push
```

## 🔄 更新 CDN 版本号（可选）

如果 CDN 缓存没有更新，可以：



## ⚠️ 注意事项

1. **CDN 缓存时间**：jsDelivr CDN 通常需要 1-5 分钟更新缓存
2. **版本号**：建议创建新版本标签（如 0.0.7），避免缓存问题
3. **文件大小**：每个文件约 8KB，总共约 120KB
4. **备份**：上传前确认本地文件完整

## 🆘 遇到问题？

如果上传失败或 CDN 无法访问：

1. 检查 GitHub 仓库是否有写入权限
2. 确认文件名格式正确（`data-page1.json`）
3. 等待几分钟后重试（CDN 缓存）
4. 使用 purge.jsdelivr.net 清除缓存
