### 方法 2：使用 Git 命令（需要 GitHub Token）

```bash
# 进入临时目录
cd /tmp/ppmenu_assets_upload

# 设置 Git 凭证（使用 Personal Access Token）
git remote set-url origin https://YOUR_TOKEN@github.com/tKyle-Libra/ppmenu_assets.git

# 推送
git push origin main
```

**如何获取 GitHub Token：**
1. 访问：https://github.com/settings/tokens
2. 点击 "Generate new token" → "Generate new token (classic)"
3. 勾选 `repo` 权限
4. 点击 "Generate token"
5. 复制生成的 token
